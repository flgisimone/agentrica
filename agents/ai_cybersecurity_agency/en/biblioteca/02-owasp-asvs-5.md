# OWASP ASVS 5.0.0

Source: owasp-asvs · Version: 5.0.0 · Verified on: 2026-11-19 · Recheck by: 2027-05-19 · Roles: AICA-02, AICA-03, AICA-10, AICA-11

## Notion
The current stable version of the Application Security Verification Standard is 5.0.0, published on 30 May 2025; it replaces 4.0.3 from 2021. Requirements have an id in the form chapter.section.requirement (e.g. 1.2.5, in Encoding and Sanitization, section Injection Prevention). Since ids change from one version to the next, ASVS recommends citing them with the version in front, with a lower-case «v»: v5.0.0-1.2.5.

## How it applies
- Always cite requirements with the version (v5.0.0-…): an id without a version is ambiguous, because the numbering of 5.0 does not match that of 4.0.3.
- If the project has controls or checklists based on 4.0.3, flag that they must be mapped to 5.0.0 and do not treat requirements with the same number as equal.
- The ASVS repository also has a development branch («Bleeding Edge»): for audits and compliance use the stable version.
