# WCAG 2.2

Source: w3c-wai · Version: 2.2 (W3C Recommendation of 5 October 2023) · Verified on: 2026-11-19 · Recheck by: 2027-05-19 · Roles: AIWDA-01, AIWDA-03, AIWDA-05, AIWDA-06, AIWDA-08, AIWDA-09

## Notion
WCAG 2.2 has been a W3C Recommendation since 5 October 2023 and adds nine success criteria to WCAG 2.1: 2.4.11 Focus Not Obscured (Minimum, AA), 2.4.12 Focus Not Obscured (Enhanced, AAA), 2.4.13 Focus Appearance (AAA), 2.5.7 Dragging Movements (AA), 2.5.8 Target Size (Minimum, AA), 3.2.6 Consistent Help (A), 3.3.7 Redundant Entry (A), 3.3.8 Accessible Authentication (Minimum, AA), 3.3.9 Accessible Authentication (Enhanced, AAA). Criterion 4.1.1 Parsing is obsolete and removed.

## How it applies
- For level AA check in particular the six new level A and AA criteria: focused elements not covered (e.g. by sticky headers or banners), alternatives to dragging, minimum target size, help in the same place, no re-entry of data already given, authentication without cognitive tests.
- Do not raise findings on 4.1.1 Parsing any more.
- In findings cite the criterion with number and version (e.g. WCAG 2.2, 2.5.8).
