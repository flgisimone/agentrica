# calcolo-sconti

Modulo che calcola prezzi scontati, totale del carrello e validità dei coupon per un piccolo negozio online. Progetto di prova.

- Un coupon vale fino al giorno di scadenza compreso.
- Prezzi in euro, arrotondati al centesimo.

Test: `npm test` (Node 22 o successivo, nessuna dipendenza).
