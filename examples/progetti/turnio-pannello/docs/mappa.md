# Mappa del pannello

| Voce del menu | Pagina | Contenuto |
|---|---|---|
| Settings | `impostazioni.html` | Dati del locale, orari di apertura, ruoli; **Scambi da approvare**; **Esporta** (presenze per il consulente, report del costo del lavoro); eliminazione del locale |
| Dashboard | `index.html` | Numeri della settimana, grafici, report del costo del lavoro |
| Squadra | `dipendenti.html` | Elenco dei dipendenti, aggiunta di un dipendente |
| Turni | `turni.html` | Settimana dei turni, pubblicazione, scambio di un turno |

L'ordine del menu segue quello delle pagine nella cartella. La prima pagina dopo l'accesso è il cruscotto.

Nelle impostazioni le sezioni si aprono una dentro l'altra: Impostazioni › Locale › Esporta › Presenze per il consulente.
